# JJBA-Quotes
A Little Repository to extract quotes of JoJo characters to use in StartPages or anything
# Monthly Quotes Selection
with a little help of ChatGPT and manual work this repository now have a Monthly Quotes Selection, every month (more specific: every day 1) GitHub get random quotes of random characters (without character repetition, only quotes repetition) from JoJo, it update the jojo quotes.csv and now every month you have new or old jjba quotes.
# Why exist?
I'm using Bonjourr, a startpage website which has some things, one of these things are "quotes", initially I was using "Inspirobot" quotes but I recently start to watch and read the JoJo series made by Hirohiko Araki, so I wanna see some quotes from these characters.

# all Characters or just the Main Ones?
ALL OF THEM, since Phantom Blood until JOJOlands (or any actual part, hello people from future lmao!), I walk on every character from the JojoWiki or Fandom and get the quotes from there, I will try to get for games and missing ones from Anime, Manga and Spin Offs too.

# How I use these 'Quotes' for my startpage or website?
well, all you need is Chose between "jojo-quotes-all.csv" or "jojo quotes.csv", copy the link of one them (or the raw link, click the three points and click in raw and copy the link), 

The "JoJo Quotes All.csv" has every quotes in sources folder (use it if you want to all the quotes shows for you), unlike the original "JoJo Quotes.csv", which only has a limited number of quotes that are updated and change every month (use it if you wanna every month a different list of quotes).

How you put this in your website ou startpage? depends which site you is using, for Bonjourr just enter the configurations, in "Quotes" click in "Quotes Type" choose URL and paste the JoJo Quotes link you copy before

Enjoy!
